Este código en Python crea un juego llamado “Adivina el número”. Primero, utiliza la función random para generar un número secreto entre 1 y 100. Luego, el jugador debe intentar descubrir cuál es ese número escribiendo diferentes opciones.

El programa cuenta los intentos realizados y, después de cada respuesta, indica si el número que escribió es más alto o más bajo que el número secreto. Cuando el jugador finalmente acierta, aparece un mensaje felicitándolo y se muestra la cantidad de intentos que necesitó.

Además, el código utiliza un ciclo while para mantener el juego activo hasta que se encuentre la respuesta correcta. También incluye try y except para controlar errores, de manera que si el usuario escribe algo que no sea un número, el programa muestra un aviso y permite continuar jugando sin cerrarse.
